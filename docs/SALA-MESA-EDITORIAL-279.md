# Mesa editorial · #279

Dirección solicita el 15-oct-2026 replantear la revisión como un libro listo para
una decisión editorial, no como una colección de controles. Continuación del
modelo CHG-SALA-TABLERO-HIDREAM-20261013: sólo SYS-SALA cambia su presentación.
Sheet/decisiones, catálogo de medios y publicación conservan contratos e identidad.

Recorrido propuesto antes de implementación: Mesa (publicaciones y pendientes)
→ libro (tira íntegra) → revisión (imagen, texto e intención juntos)
→ comparar tomas → aprobar explícitamente o pedir un cambio con nota.
Volver y navegar nunca votan. El gesto vertical deja de aprobar: en móvil se
necesita para leer. Las flechas laterales sólo comparan. El envío y su acuse
siguen bajo el guardado existente; una marca visual no acredita producción.

La mesa usa el ancho disponible, una publicación por renglón y una tira legible.
El libro conserva la secuencia como índice de páginas, contexto editorial,
comparación simultánea y acción principal inequívoca. Una toma ausente, una
lectura fallida o un rol lector/agente no se convierten en aprobación.
No se inventan recomendaciones, calidad perfecta, producción ni contenido.

Pruebas: Node, verificador de Sala, navegador sintético escritorio/móvil/iframe;
comparar sin escrituras, índice original tras vetos, desplazamiento sin voto,
retorno y notas, imagen fallida, roles y ausencia de desbordamiento. QA publicada
sólo lectura. Reversión por PR conserva medios, borradores, votos e historial.
